# 🕵️ Motion Detection with OpenCV

A simple real-time motion detection system using your webcam, built with Python, OpenCV, and Imutils. This project captures video input and detects motion by comparing the live feed to a reference frame.

---

## 📷 Preview

> Live video stream with motion detection — moving objects are highlighted with green bounding boxes.

---

## 🛠️ Requirements

- Python 3.x
- OpenCV (`cv2`)
- Imutils
